# Memory-Forest

## Gameplay

Run the project from `scenes/Main.tscn`. Clear five rooms to conquer the forest; if the player falls, the next generation earns Memory based on the deepest room reached and can spend it at the shrine.

Controls: WASD to move, Shift to dash, Space for a light attack, and E for a heavy attack.

Shrine upgrades persist between generations: Health adds 20 maximum HP for 2 Memory; Attack adds 20% damage, Movement adds 10% speed, and Attack Speed adds 15% attack speed for 3 Memory each. Each repeat purchase costs 2 more Memory than the previous one.
